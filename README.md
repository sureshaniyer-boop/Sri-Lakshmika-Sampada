# Sri Lakshmika Sampada

Premium, mobile-responsive demonstration storefront for **Sri Lakshmika Sampada**, featuring four Aari blouse collections:

- Elegance
- Premium Elegance
- Royal Bridal Collection
- Ready-to-Wear Elegance

## Live site
Once GitHub Pages has been configured under **Settings → Pages → Source: GitHub Actions**, the intended URL is:

https://sureshaniyer-boop.github.io/Sri-Lakshmika-Sampada/

## Owner configuration
Edit `products.js` to add your business WhatsApp number (`whatsappNumber`, with Malaysia country code 60 and no plus sign), Instagram/TikTok URLs, real product data, images, pricing and available sizes.

**The current catalogue includes illustrative product art and sample design names only.** Suggested price bands are marketing planning ranges, not firm offers. Please verify stock and prices before publicly advertising products.

## Files
- `index.html`: boutique storefront
- `styles.css`: desktop, tablet and mobile styling
- `products.js`: sample catalogue and store settings
- `script.js`: search, category filters, shortlist and customer enquiries
- `images/`: illustrative blouse artwork (not product photography)
- `assets/sri-lakshmika-logo.svg`: a temporary simplified vector approximation of the supplied lotus emblem, **not** the final high-resolution original brand artwork
- `.github/workflows/deploy-pages.yml`: GitHub Actions Pages deployment

To replace the temporary logo with the **exact supplied original**, upload your PNG image as `assets/sri-lakshmika-logo.png` and replace the `assets/sri-lakshmika-logo.svg` occurrences in `index.html` with the PNG path (and adjust the favicon's type).

No payment gateway, user accounts, live inventory or automatic order fulfilment are configured.
